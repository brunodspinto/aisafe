# Glossary

| ***TEA*** (EN)                                                                        | ***TEA*** (PT)                        | ***Description*** (EN)                                                                                                                                                                                                                                    |
|:--------------------------------------------------------------------------------------|:--------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **<a id="admin">Admin</a>**                                                           | **Administrador**                     | User role responsible for registering, disabling/enabling, and listing backoffice users. Also directly manages <a href="#flight-control-operator">Flight Control Operators</a> due to security concerns.                                                  |
| **<a id="air-control-area">Air Control Area</a>**                                     | **Área de Controlo Aéreo**            | A geographic area with a unique code and valid boundaries where <a href="#flight">Flights</a> are simulated and monitored for safety.                                                                                                                     |
| **<a id="air-control-area-collaborator">Air Control Area Collaborator</a>**           | **Colaborador da Área de Controlo**   | System user associated with an <a href="#air-control-area">Air Control Area</a>, responsible for managing flight-related operations within that area. A specialisation of <a href="#customer-collaborator">Customer Collaborator</a>.                     |
| **<a id="air-transport-company">Air Transport Company</a>**                           | **Companhia de Transporte Aéreo**     | Entity that registers <a href="#aircraft">Aircraft</a> and <a href="#flight">Flights</a>, identified by a unique name, <a href="#iata">IATA</a>, and <a href="#icao">ICAO</a> codes.                                                                      |
| **<a id="air-transport-company-collaborator">Air Transport Company Collaborator</a>** | **Colaborador da Companhia Aérea**    | System user associated with an <a href="#air-transport-company">Air Transport Company</a> who can register <a href="#aircraft">Aircraft</a>, <a href="#route">Flight Routes</a>, and manage <a href="#pilot">Pilots</a>. A specialisation of <a href="#customer-collaborator">Customer Collaborator</a>. |
| **<a id="aircraft">Aircraft</a>**                                                     | **Aeronave**                          | A motorized commercial aircraft of a specific <a href="#aircraft-model">Aircraft Model</a>, identified by a unique registration number, and operated by an <a href="#air-transport-company">Air Transport Company</a>.                                    |
| **<a id="aircraft-model">Aircraft Model</a>**                                         | **Modelo de Aeronave**                | Specification of an aircraft including its ID, maker, type, motorization, and weights like <a href="#mtow">MTOW</a> and <a href="#mzfw">MZFW</a>, requiring at least one certified <a href="#engine-model">Engine Model</a>.                              |
| **<a id="airport">Airport</a>**                                                       | **Aeroporto**                         | Location associated with exactly one <a href="#air-control-area">Air Control Area</a>, having unique <a href="#icao">ICAO</a> and <a href="#iata">IATA</a> codes and valid coordinates.                                                                   |
| **<a id="airport-code">Airport Code</a>**                                             | **Código de Aeroporto**               | A Value Object representing either the <a href="#iata">IATA</a> or <a href="#icao">ICAO</a> code, used strictly as an external reference to identify an <a href="#airport">Airport</a>.                                                                   |
| **<a id="ast">AST</a>**                                                               | **AST (Árvore de Sintaxe Abstrata)**  | Abstract Syntax Tree. Internal representation of a <a href="#flight-plan">Flight Plan</a> produced using ANTLR after processing the <a href="#core-flight-dsl">Core Flight DSL</a>.                                                                       |
| **<a id="backoffice-operator">Backoffice Operator</a>**                               | **Operador de Backoffice**            | System user who configures system information such as <a href="#aircraft-model">Aircraft Models</a>, <a href="#airport">Airports</a>, and <a href="#air-control-area">Air Control Areas</a>.                                                              |
| **<a id="cabin-configuration">Cabin Configuration</a>**                               | **Configuração de Cabine**            | The specific distribution of passenger seats (e.g., first class, business, economy) inside an <a href="#aircraft">Aircraft</a>.                                                                                                                           |
| **<a id="core-flight-dsl">Core Flight DSL</a>**                                       | **DSL de Voo Principal**              | Domain Specific Language used to describe and validate <a href="#flight-plan">Flight Plans</a>.                                                                                                                                                           |
| **<a id="customer-collaborator">Customer Collaborator</a>**                           | **Colaborador do Cliente**            | Generic term for a system user who belongs to either an <a href="#air-transport-company">Air Transport Company</a> or an <a href="#air-control-area">Air Control Area</a>. Encompasses both <a href="#air-transport-company-collaborator">Air Transport Company Collaborators</a> and <a href="#air-control-area-collaborator">Air Control Area Collaborators</a>. |
| **<a id="drag">Drag</a>**                                                             | **Arrasto**                           | Force acting on the <a href="#aircraft">Aircraft</a>, calculated using aerodynamic parameters.                                                                                                                                                            |
| **<a id="email">Email</a>**                                                           | **Email**                             | Value Objects representing the electronic mail address used to authenticate and identify a <a href="#user">User</a> in the system.                                                                                                                        |
| **<a id="engine-model">Engine Model</a>**                                             | **Modelo de Motor**                   | Specification of an aircraft engine, characterized by its type, thrust, and <a href="#tsfc">TSFC</a>, produced by a <a href="#maker">Maker</a>.                                                                                                           |
| **<a id="engine-type">Engine Type</a>**                                               | **Tipo de Motor**                     | Classification of an <a href="#engine-model">Engine Model</a> based on its propulsion mechanism. Valid types are TURBOFAN, TURBOPROP, TURBOJET, RAMJET, and ELECTRIC_PROPELLER.                                                                           |
| **<a id="fleet">Fleet</a>**                                                           | **Frota**                             | The collection of <a href="#aircraft">Aircraft</a> registered to an <a href="#air-transport-company">Air Transport Company</a>, identified by their registration numbers.                                                                                  |
| **<a id="flight">Flight</a>**                                                         | **Voo**                               | Connection between two <a href="#airport">Airports</a>, based on a <a href="#route">Route</a>, with schedule and designator.                                                                                                                              |
| **<a id="flight-control-operator">Flight Control Operator</a>**                       | **Operador de Controlo de Voo**       | System user responsible for testing <a href="#flight-plan">Flight Plans</a> and simulating safety within an <a href="#air-control-area">Air Control Area</a>.                                                                                             |
| **<a id="flight-designator">Flight Designator</a>**                                   | **Designador de Voo**                 | A unique identifier for a <a href="#flight">Flight</a>, formatted as 'xxn(n)(n)(n)(a)'. It concatenates a two-letter airline designator ('xx'), a numeric flight number of up to four digits, and an optional one-letter operational suffix ('a'). Also used inside <a href="#safety-violation">Safety Violation</a> records to identify the involved flight. |
| **<a id="flight-plan">Flight Plan</a>**                                               | **Plano de Voo**                      | Document describing how a <a href="#flight">Flight</a> is executed, defined using the <a href="#core-flight-dsl">Core Flight DSL</a>.                                                                                                                     |
| **<a id="flights-logging-server">Flights Logging Server</a>**                         | **Servidor de Registo de Voos**       | UDP-based server that receives updates from flight processes and provides an HTTP status page.                                                                                                                                                            |
| **<a id="flight-segment">Flight Segment</a>**                                         | **Segmento de Voo**                   | A linear path between two geographic points within a <a href="#flight-plan">Flight Plan</a>, characterised by allowed altitude slots, width per slot, wind direction and wind speed.                                                                      |
| **<a id="geoboundary">GeoBoundary</a>**                                               | **Fronteira Geográfica**              | The geometric rectangular boundaries (coordinates) that define the physical limits of an <a href="#air-control-area">Air Control Area</a>.                                                                                                                |
| **<a id="geo-coordinate">GeoCoordinate</a>**                                          | **Coordenada Geográfica**             | Value Object representing a single geographic point (latitude and longitude) used to define the location of an <a href="#airport">Airport</a>. Distinct from <a href="#geoboundary">GeoBoundary</a>, which defines an area's rectangular boundaries.      |
| **<a id="iata">IATA</a>**                                                             | **IATA**                              | Code format identifying <a href="#air-transport-company">Companies</a> (2 letters) or <a href="#airport">Airports</a> (3 letters).                                                                                                                        |
| **<a id="icao">ICAO</a>**                                                             | **ICAO**                              | Code format identifying <a href="#air-transport-company">Companies</a> (2–3 letters) or <a href="#airport">Airports</a> (4 letters).                                                                                                                      |
| **<a id="leg">Leg</a>**                                                               | **Etapa**                             | A single non-stop journey between two <a href="#airport">Airports</a>.                                                                                                                                                                                    |
| **<a id="lift">Lift</a>**                                                             | **Sustentação**                       | Upward aerodynamic force acting on an <a href="#aircraft">Aircraft</a>.                                                                                                                                                                                   |
| **<a id="maker">Maker</a>**                                                           | **Fabricante**                        | An entity or company (e.g., Airbus, Rolls-Royce) that manufactures <a href="#aircraft-model">Aircraft Models</a> or <a href="#engine-model">Engine Models</a>.                                                                                            |
| **<a id="mecanographic-number">Mecanographic Number</a>**                             | **Número Mecanográfico**              | Unique identifier assigned to a <a href="#user">User</a> in the AISafe system, used as the aggregate identity of the User domain entity.                                                                                                                  |
| **<a id="mtow">MTOW</a>**                                                             | **Peso Máximo de Descolagem**         | Maximum Take-Off Weight of an <a href="#aircraft-model">Aircraft Model</a>.                                                                                                                                                                               |
| **<a id="mzfw">MZFW</a>**                                                             | **Peso Máximo sem Combustível**       | Maximum Zero Fuel Weight of an <a href="#aircraft-model">Aircraft Model</a>.                                                                                                                                                                              |
| **<a id="node-junction">Node/Junction</a>**                                           | **Nó/Junção**                         | Connection between multiple <a href="#segment">Segments</a> allowing movement.                                                                                                                                                                            |
| **<a id="operational-status">Operational Status</a>**                                 | **Estado Operacional**                | The current status of an <a href="#aircraft">Aircraft</a> in the system. An aircraft starts as ACTIVE and may be set to DECOMMISSIONED upon retirement (US071).                                                                                           |
| **<a id="pilot">Pilot</a>**                                                           | **Piloto**                            | Certified user responsible for operating aircraft and registering <a href="#flight-plan">Flight Plans</a>.                                                                                                                                                |
| **<a id="project-manager">Project Manager</a>**                                       | **Gestor de Projeto**                 | Role overseeing project structure and Domain Model development.                                                                                                                                                                                           |
| **<a id="registration-number">Registration Number</a>**                               | **Número de Registo**                 | Globally unique alphanumeric identifier assigned to an <a href="#aircraft">Aircraft</a>, used as its aggregate identity. An aircraft is registered in a country which may differ from the company's home country.                                         |
| **<a id="role">Role</a>**                                                             | **Papel**                             | The functional responsibility assigned to a <a href="#user">User</a> in the system, determining which operations that user is authorised to perform. A user may be an Admin, Backoffice Operator, ATCC, Pilot, Flight Control Operator or Weather Person. |
| **<a id="route">Route</a>**                                                           | **Rota**                              | Planned path between two <a href="#airport">Airports</a> with a unique identifier.                                                                                                                                                                        |
| **<a id="safety-violation">Safety Violation</a>**                                     | **Violação de Segurança**             | An event recorded during a <a href="#simulation">Simulation</a> indicating that a <a href="#flight">Flight</a> breached safety thresholds.                                                                                                                |
| **<a id="security-clearance">Security Clearance</a>**                                 | **Credencial de Segurança**           | A verification status and expiration date associated with a <a href="#user">User</a> to determine their access level.                                                                                                                                     |
| **<a id="security-level">Security Level</a>**                                         | **Nível de Segurança**                | The clearance tier associated with a <a href="#user">User</a>, defined by five levels in ascending order: LOW, GUARDED, ELEVATED, HIGH, and CRITICAL. Levels ELEVATED and above require a body scan. Part of <a href="#security-clearance">Security Clearance</a>. |
| **<a id="segment">Segment</a>**                                                       | **Segmento**                          | Linear path between two points with constraints like altitude and wind.                                                                                                                                                                                   |
| **<a id="service-ceiling">Service Ceiling</a>**                                       | **Teto de Serviço**                   | The maximum altitude at which a specific <a href="#aircraft-model">Aircraft Model</a> can safely operate.                                                                                                                                                 |
| **<a id="simulation">Simulation</a>**                                                 | **Simulação**                         | Execution of programmed <a href="#flight">Flights</a> within an <a href="#air-control-area">Air Control Area</a> to detect <a href="#safety-violation">Safety Violations</a>.                                                                             |
| **<a id="simulation-report">Simulation Report</a>**                                   | **Relatório de Simulação**            | Document generated after a <a href="#simulation">Simulation</a>, summarizing execution and violations.                                                                                                                                                    |
| **<a id="simulation-step">Simulation Step</a>**                                       | **Passo de Simulação**                | A discrete unit of time in the flight <a href="#simulation">Simulation</a> engine. All flight processes must submit their position updates at each step before the simulation advances to the next, ensuring temporal consistency.                         |
| **<a id="tas">TAS</a>**                                                               | **Velocidade Verdadeira do Ar**       | True Air Speed. Speed of an <a href="#aircraft">Aircraft</a> relative to air.                                                                                                                                                                             |
| **<a id="tsfc">TSFC</a>**                                                             | **Consumo Específico de Combustível** | Thrust Specific Fuel Consumption, indicating engine efficiency.                                                                                                                                                                                           |
| **<a id="user">User</a>**                                                             | **Utilizador**                        | A person interacting with the system, authenticated and assigned roles (e.g., <a href="#pilot">Pilot</a>, <a href="#admin">Admin</a>).                                                                                                                    |
| **<a id="weather-data">Weather Data</a>**                                             | **Dados Meteorológicos**              | Environmental information (wind speed, temperature, visibility) recorded for a specific <a href="#air-control-area">Air Control Area</a>.                                                                                                                 |
| **<a id="weather-person">Weather Person</a>**                                         | **Responsável Meteorológico**         | User responsible for managing weather data for <a href="#air-control-area">Air Control Areas</a>.                                                                                                                                                         |
| **<a id="weather-source">Weather Source</a>**                                         | **Fonte Meteorológica**               | External provider from which <a href="#weather-data">Weather Data</a> was imported.                                                                                                                                                                       |
