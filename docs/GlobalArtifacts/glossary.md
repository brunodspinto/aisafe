# Glossary

| ***TEA*** (EN)                                                                        | ***Description*** (EN)                                                                                                                                                                                                                                |
|:--------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **<a id="admin">Admin</a>**                                                           | User role responsible for registering, disabling/enabling, and listing backoffice users. Also directly manages <a href="#flight-control-operator">Flight Control Operators</a> due to security concerns.                                              |
| **<a id="air-control-area">Air Control Area</a>**                                     | A geographic area with a unique code and valid boundaries where <a href="#flight">Flights</a> are simulated and monitored for safety.                                                                                                                 |
| **<a id="air-transport-company">Air Transport Company</a>**                           | Entity that registers <a href="#aircraft">Aircraft</a> and <a href="#flight">Flights</a>, identified by a unique name, <a href="#iata">IATA</a>, and <a href="#icao">ICAO</a> codes.                                                                  |
| **<a id="air-transport-company-collaborator">Air Transport Company Collaborator</a>** | System user who can register <a href="#aircraft">Aircraft</a>, <a href="#route">Flight Routes</a>, and manage <a href="#pilot">Pilots</a>.                                                                                                            |
| **<a id="aircraft">Aircraft</a>**                                                     | A motorized commercial aircraft of a specific <a href="#aircraft-model">Aircraft Model</a>, identified by a unique registration number, and operated by an <a href="#air-transport-company">Air Transport Company</a>.                                |
| **<a id="aircraft-model">Aircraft Model</a>**                                         | Specification of an aircraft including its ID, maker, type, motorization, and weights like <a href="#mtow">MTOW</a> and <a href="#mzfw">MZFW</a>, requiring at least one certified engine model.                                                      |
| **<a id="airport">Airport</a>**                                                       | Location associated with exactly one <a href="#air-control-area">Air Control Area</a>, having unique <a href="#icao">ICAO</a> and <a href="#iata">IATA</a> codes and valid coordinates.                                                               |
| **<a id="ast">AST</a>**                                                               | Abstract Syntax Tree. Internal representation of a <a href="#flight-plan">Flight Plan</a> produced using ANTLR after processing the <a href="#core-flight-dsl">Core Flight DSL</a>.                                                                   |
| **<a id="backoffice-operator">Backoffice Operator</a>**                               | System user who configures system information such as <a href="#aircraft-model">Aircraft Models</a>, <a href="#airport">Airports</a>, and <a href="#air-control-area">Air Control Areas</a>.                                                          |
| **<a id="core-flight-dsl">Core Flight DSL</a>**                                       | Domain Specific Language used to describe and validate <a href="#flight-plan">Flight Plans</a>.                                                                                                                                                       |
| **<a id="drag">Drag</a>**                                                             | Force acting on the <a href="#aircraft">Aircraft</a>, calculated using aerodynamic parameters.                                                                                                                                                        |
| **<a id="flight">Flight</a>**                                                         | Connection between two <a href="#airport">Airports</a>, based on a <a href="#route">Route</a>, with schedule and designator.                                                                                                                          |
| **<a id="flight-control-operator">Flight Control Operator</a>**                       | System user responsible for testing <a href="#flight-plan">Flight Plans</a> and simulating safety within an <a href="#air-control-area">Air Control Area</a>.                                                                                         |
| **<a id="flight-plan">Flight Plan</a>**                                               | Document describing how a <a href="#flight">Flight</a> is executed, defined using the <a href="#core-flight-dsl">Core Flight DSL</a>.                                                                                                                 |
| **<a id="flights-logging-server">Flights Logging Server</a>**                         | UDP-based server that receives updates from flight processes and provides an HTTP status page.                                                                                                                                                        |
| **<a id="iata">IATA</a>**                                                             | Code format identifying <a href="#air-transport-company">Companies</a> (2 letters) or <a href="#airport">Airports</a> (3 letters).                                                                                                                    |
| **<a id="icao">ICAO</a>**                                                             | Code format identifying <a href="#air-transport-company">Companies</a> (2–3 letters) or <a href="#airport">Airports</a> (4 letters).                                                                                                                  |
| **<a id="leg">Leg</a>**                                                               | A single non-stop journey between two <a href="#airport">Airports</a>.                                                                                                                                                                                |
| **<a id="lift">Lift</a>**                                                             | Upward aerodynamic force acting on an <a href="#aircraft">Aircraft</a>.                                                                                                                                                                               |
| **<a id="mtow">MTOW</a>**                                                             | Maximum Take-Off Weight of an <a href="#aircraft-model">Aircraft Model</a>.                                                                                                                                                                           |
| **<a id="mzfw">MZFW</a>**                                                             | Maximum Zero Fuel Weight of an <a href="#aircraft-model">Aircraft Model</a>.                                                                                                                                                                          |
| **<a id="node-junction">Node/Junction</a>**                                           | Connection between multiple <a href="#segment">Segments</a> allowing movement.                                                                                                                                                                        |
| **<a id="pilot">Pilot</a>**                                                           | Certified user responsible for operating aircraft and registering <a href="#flight-plan">Flight Plans</a>.                                                                                                                                            |
| **<a id="project-manager">Project Manager</a>**                                       | Role overseeing project structure and Domain Model development.                                                                                                                                                                                       |
| **<a id="route">Route</a>**                                                           | Planned path between two <a href="#airport">Airports</a> with a unique identifier.                                                                                                                                                                    |
| **<a id="segment">Segment</a>**                                                       | Linear path between two points with constraints like altitude and wind.                                                                                                                                                                               |
| **<a id="tas">TAS</a>**                                                               | True Air Speed. Speed of an <a href="#aircraft">Aircraft</a> relative to air.                                                                                                                                                                         |
| **<a id="tsfc">TSFC</a>**                                                             | Thrust Specific Fuel Consumption, indicating engine efficiency.                                                                                                                                                                                       |
| **<a id="weather-person">Weather Person</a>**                                         | User responsible for managing weather data for <a href="#air-control-area">Air Control Areas</a>.                                                                                                                                                     |
